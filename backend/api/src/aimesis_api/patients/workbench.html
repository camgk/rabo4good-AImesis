Checking patient storage…

Patient record

A new BSA value is saved as a dated observation. Older observations remain in the record; calculations use the newest measurement time, not the last row entered.

Recorded chemotherapy

Record the chemotherapy dose in mg/m² and the administration days, such as 1,2,3,4,5. These determine the baseline strategy through Story 1.

Calculation options

Each medicine follows its own policy: BSA-based, weight-based, age-based or a fixed dose. Rescue ranges and alternative agents require clinician selection.
