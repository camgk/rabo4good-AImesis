STEP 1 · OVERVIEW

Solve With Google Workshop

Team-based workshop overview and learning objectives for your dedicated Google Cloud environment.

Overview

This workshop is designed as a team-based workshop for a team of 5 members, it provides you with a dedicated Google Cloud project where you are granted Owner access.

You will have access to 5 Antigravity Virtual Machines (VMs) provisioned specifically for your use. Each VM comes pre-configured with essential tools and environments, including:

  • Antigravity Agent Platform
  • AGY CLI
  • Google Cloud SDK
  • Google Chrome browser
  • Visual Studio Code (VS Code)
  • Konsole (built-in terminal)

Objectives

In this workshop, you will learn how to:

  • Access your dedicated Google Cloud project.
  • Connect to and utilize the pre-configured Antigravity VM.
  • Familiarize yourself with the Antigravity Agent Platform and AGY CLI.
  • Leverage the provided tools within the VM environment.

STEP 2 · ENVIRONMENT SETUP

Setup and requirements

Prepare your credentials and establish clipboard access with your Antigravity VM remote desktop.

For this workshop, you'll be given access to a temporary GCP environment with ephemeral credentials. Start by registering with your email on the Explore page:

Once you're in, expand Credentials Reference to find your temporary username, password, and project ID.

Noting your credentials, right-click Antigravity in a VM and select Open Link in Incognito Window

When you see the pop-up about seeing text and images copied to the clipboard, select Accept. This will allow you to copy and paste prompts from these instructions into Antigravity.

STEP 3 · PLATFORM AUTHENTICATION

Authenticate Google Antigravity Agent Platform

Step-by-step sign-in process for the Antigravity 2.0 Agent Platform environment.

In the Webtop Remote Desktop, to access Antigravity 2.0 Agent Platform and Visual Studio Code, click Application Launcher > Development. Visual Studio Code also has an icon on the desktop.

Note: If the Webtop Remote Desktop freezes or shows waiting for stream, refresh the browser tab. If that does not help, open the Webtop Remote Desktop link in a new tab. Your files and Antigravity history are kept. If it still does not recover, contact event support.

  1. When Antigravity 2.0 launches, click Use business account.

  2. On the Sign in with business account screen, click Continue with Google Cloud.

  3. If you are presented with the Welcome console for the Chrome browser, click OK.

  4. On the Sign in to Chrome console, click Stay signed out.

  5. In the next console, use your workshop credentials to complete the sign-in process.

  6. Click Use Chrome without an account, and then click Sign in.

  7. When the Open Antigravity? dialog appears, ignore it and minimize the Chrome browser window.

  8. In the Antigravity 2.0 console, on the Select your license page:

    • Under Provide Google Cloud Project, enter your Google Cloud Project ID.
    • Under Choose Region, select Global.
    • Under Select License, click Use Agent Platform instead, and then click Next.

  9. Complete the Antigravity 2.0 setup wizard using the following configurations, leave the remaining settings as their defaults, and click Next after each page:

    Page Configuration
    Terms of Service & Data Use Click Next
    Select Antigravity Theme Select your theme of choice (System/Light/Dark)
    Build with Google Select Google Antigravity SDK

  10. Click Finish. Your Antigravity environment appears.

STEP 4 · COMMAND-LINE TOOLS

Authenticate AGY CLI

Authenticate the command-line interface directly within Konsole to interact with the Antigravity Agent Platform.

Open Konsole terminal using Application Launcher > System > Konsole.

Run the following command to start the Antigravity CLI:

BASH 
agy

First-time authentication: The first time you run agy in your Remote Desktop, it prompts you to authenticate.

STEP 5 · CLOUD STORAGE

Access Use Case Materials from Cloud Storage

Download and open pre-uploaded datasets and reference documents for your team's use case.

All workshop use case datasets and reference documents are pre-uploaded to a dedicated Cloud Storage bucket. You can download the use case files using following instructions:

Using the Konsole Terminal (Recommended for Antigravity / VS Code) or CloudShell

  1. Open Konsole in your Antigravity Remote Desktop (Application Launcher > System > Konsole).
  2. Run the following commands to download the use case materials into a local /config/Desktop/use-cases folder on your VM:
BASH 
mkdir -p /config/Desktop/use-cases & gcloud storage cp -r "gs://swg-workshop/use-case/*" /config/Desktop/use-cases/
  1. Once downloaded, you can open /config/Desktop/use-cases directly in Antigravity Agent Platform or Visual Studio Code.
