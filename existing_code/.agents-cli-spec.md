## Overview
AImesis (`uc3-aimesis-cinv`) is a pediatric oncology Clinical Decision Support (CDS) agent built with the Google Agent Development Kit (ADK). Grounded in UZA's July 2026 v2 policy (`Anti-emetica beleid CINV - V2.pdf`), the official 87-page POGO Emetogenicity Classification Guideline (`POGO Emetogenicity Classification Guideline Final-rev- 250111.pdf`), and UZA's 3 clinical case examples (`casus voorbeelden.docx`), it assists pediatric oncology clinicians, nurses, and clinical pharmacists in preventing Chemotherapy-Induced Nausea and Vomiting (CINV) by classifying multi-agent chemotherapy emetogenicity (including combination escalations like `Ifosfamide + Etoposide -> High`), aligning prophylaxis with pediatric age, BSA/weight, and route/formulation constraints, screening for high-risk drug-drug interactions (CYP3A4 inhibition from azoles or aprepitant, and additive QTc prolongation), generating an individualized CINV Patient Passport, and supporting parent/patient companion app symptom logging.

## Goal
Harmonize multi-agent pediatric chemotherapy regimens with international guidelines (POGO, MASCC, ESMO) while factoring in age-specific contraindications, anticipatory nausea, and polypharmacy drug-drug interactions (DDIs), outputting transparent, citation-backed advisory regimens that require clinician sign-off.

### Architecture Options Weighed (Phase 0 Brainstorming & EGM Lenses)
1. **Option A — Single `LlmAgent` with Deterministic Clinical Tools (Recommended & Selected for MVP)**:
   - One `root_agent` (`gemini-2.5-flash`) orchestrating four deterministic Python tools backed by curated in-memory POGO/MASCC tables and DDI/QTc rules.
   - *Rationale (Contrarian/YAGNI & Cost/Token Economics)*: Emetogenicity classification, CYP3A4 dose adjustments (e.g., 50% dexamethasone reduction with aprepitant), and QTc risk flags must be deterministic and reproducible rather than hallucinated by free-text LLM reasoning or over-engineered multi-agent handoffs.
2. **Option B — Multi-Agent Sequential Pipeline (`SequentialAgent`)**:
   - Separate sub-agents for Emetogenicity Classifier -> Guideline Mapper -> DDI Pharmacist -> Risk Adjuster.
   - *Trade-off*: Increases latency and token overhead 4x for an MVP where deterministic functions already isolate each domain step cleanly. Deferred until specialist sub-agents require independent toolsets or context isolation.
3. **Option C — Full RAG + FHIR EHR Integration**:
   - Vector search over full POGO/MASCC/ESMO PDFs + live hospital EHR medication orders.
   - *Trade-off*: Over-scoped for initial validation; deferred to Future Phases via `core/python/rag-agent-search` and `core/python/safety-plugins`.

## Inputs and Outputs
- **Inputs**:
  - Chemotherapy regimen drugs list (e.g., `["cisplatin", "doxorubicin"]` or `["vincristine", "methotrexate"]`).
  - Patient age in years (or months for infants) and administration route (`"IV"` or `"PO"`).
  - Concomitant medications (e.g., `"voriconazole"`, `"posaconazole"`, `"fluconazole"`, `"vincristine"`).
  - Patient-specific emetic risk factors (e.g., `["prior_cinv", "high_anxiety", "motion_sickness", "age_under_6_months"]`).
- **Outputs**:
  - Structured clinical decision support summary containing:
    1. Per-drug and overall regimen emetogenicity tier (`High`, `Moderate`, `Low`, `Minimal`).
    2. Age-appropriate POGO/MASCC baseline antiemetic prophylaxis regimen.
    3. Explicit DDI & QTc safety report (severity, mechanism, and required dose modifications such as dexamethasone CYP3A4 adjustment or NK1 deferral with strong azoles).
    4. Risk-adjusted regimen escalation/modifications (e.g., lorazepam or olanzapine adjuncts for anticipatory CINV or refractory history).
    5. Mandatory safety banner: `"Advisory Only — Requires Clinician Sign-Off"`.

## Example Use Cases
1. **High Emetogenic Regimen + Azole Antifungal Prophylaxis**:
   - *Input*: 9-year-old receiving IV cisplatin + doxorubicin, currently on voriconazole prophylaxis, with a history of prior CINV.
   - *Expected Output*: Classifies regimen as `High` emetogenic risk (HEC); recommends 5-HT3 antagonist (granisetron or ondansetron) + dexamethasone + NK1 antagonist (aprepitant); flags `CONTRAINDICATED / HIGH SEVERITY` CYP3A4 interaction between voriconazole and aprepitant plus additive QTc risk (voriconazole + ondansetron), recommending switching to granisetron + ECG monitoring, holding/adjusting aprepitant, reducing dexamethasone dose by 50% if NK1/strong CYP3A4 inhibitor is co-administered, and adding rescue/breakthrough olanzapine for prior CINV. Ends with `"Advisory Only — Requires Clinician Sign-Off"`.
2. **Infant (< 6 Months) Moderate Emetogenic Regimen**:
   - *Input*: 0-year-old (4 months) infant receiving IV cyclophosphamide + cytarabine, risk factor `["age_under_6_months"]`.
   - *Expected Output*: Classifies as `Moderate` emetogenic risk (MEC); adjusts POGO recommendation for infants under 6 months (aprepitant generally approved >= 6 months; prioritizes weight-adjusted 5-HT3 antagonist + corticosteroid if not contraindicated by oncology protocol); includes mandatory clinician sign-off label.

## Tools and Data Sources
### Tools Required
All tools are implemented as deterministic Python functions in `app/agent.py` using curated in-memory pediatric oncology reference tables (no external auth required for MVP):

1. `classify_regimen_emetogenicity(chemo_drugs_list: list[str]) -> dict`
   - **Purpose**: Evaluates each antineoplastic agent against POGO/MASCC pediatric emetogenicity tiers (`High` >=90%, `Moderate` 30-90%, `Low` 10-30%, `Minimal` <10%) and computes the overall regimen tier (driven by the highest-risk agent or synergistic combination rules such as cyclophosphamide + anthracycline).
2. `check_ddi_interactions(primary_drugs: list[str], proposed_antiemetics: list[str]) -> dict`
   - **Purpose**: Screens for pharmacokinetic (CYP3A4 inhibition/induction) and pharmacodynamic (additive QTc prolongation, neurotoxicity) interactions across primary chemotherapy, concomitant medications (especially azole antifungals: voriconazole, posaconazole, itraconazole, fluconazole), and antiemetics (ondansetron, granisetron, palonosetron, aprepitant, fosaprepitant, dexamethasone, olanzapine, lorazepam).
3. `get_pogo_guideline_recommendation(emetogenic_tier: str, age: int, route: str = "IV") -> dict`
   - **Purpose**: Returns the baseline POGO/MASCC pediatric antiemetic prophylaxis regimen stratified by emetogenic tier (`High`, `Moderate`, `Low`, `Minimal`), patient age in years (handling <1 yr, 1-11 yr, >=12 yr pediatric dosing tiers), and preferred route (`IV` or `PO`), with guideline citations.
4. `calculate_risk_adjusted_regimen(base_regimen: str, patient_risk_factors: list[str]) -> dict`
   - **Purpose**: Adjusts the baseline prophylaxis regimen for patient-specific modifiers (`prior_cinv`, `anticipatory_nausea`, `high_anxiety`, `motion_sickness`, `cns_tumor_or_steroid_restricted`, `qtc_prolongation_baseline`, `hepatic_impairment`, `age_under_6_months`) and embeds the mandatory `"Advisory Only — Requires Clinician Sign-Off"` regulatory label.

## Constraints and Guardrails
### Constraints & Safety Rules
1. **Mandatory Regulatory Banner**: Every final recommendation and `calculate_risk_adjusted_regimen` output MUST explicitly include `"Advisory Only — Requires Clinician Sign-Off"`.
2. **No Autonomous Prescribing**: The agent must never claim to place EHR orders, prescribe medications directly, or override a treating pediatric oncologist's protocol (e.g., when corticosteroids are prohibited in CNS tumors or ALL induction/blina/CAR-T protocols).
3. **Deterministic Tool Grounding**: The agent must always call all four tools (`classify_regimen_emetogenicity`, `get_pogo_guideline_recommendation`, `check_ddi_interactions`, `calculate_risk_adjusted_regimen`) when constructing a complete regimen recommendation rather than guessing emetogenic tiers or interactions from model weights.
4. **Explicit Guideline Citations**: Every clinical recommendation must cite the corresponding POGO / MASCC pediatric guideline rule.
5. **Zero Hardcoded Secrets & Strict Workspace Isolation**: No credentials in code; all artifacts remain strictly within `/usr/local/google/home/jpaquay/.gemini/jetski/scratch/swg2026/uc3-aimesis-cinv-ws`.

## Success Criteria
1. **Tool Load & Contract Verification**: `root_agent` loads with all 4 required tools (`classify_regimen_emetogenicity`, `check_ddi_interactions`, `get_pogo_guideline_recommendation`, `calculate_risk_adjusted_regimen`) and passes deterministic unit/smoke assertions (`100%` pass rate).
2. **DDI & QTc Detection Recall**: `check_ddi_interactions` detects `100%` of seeded high-risk interactions (azole + aprepitant CYP3A4 overload, aprepitant + dexamethasone 50% dose reduction rule, ondansetron + azole additive QTc prolongation, and azole + vincristine neurotoxicity warning).
3. **Regulatory Sign-Off Compliance**: `100%` of regimen outputs include `"Advisory Only — Requires Clinician Sign-Off"` and POGO/MASCC citations.
